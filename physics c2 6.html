Vector Addition

Resultant Vectors, Head-to-Tail Geometry, the Parallelogram Law, and Special Angle Cases

1 The Resultant Vector (\(\vec{R}\))

Definition:

A resultant vector is a single combined vector obtained by adding two or more individual vectors together, usually denoted by \(\vec{R}\):

$$\boxed{\vec{R} = \vec{A} + \vec{B}}$$
Collinear Example:

Walking \(4\text{ m east}\) followed by \(3\text{ m east}\) produces a single net displacement:

\(\vec{R} = 4\text{ m} + 3\text{ m} = 7\text{ m east}\)

2 Graphical Method (Head-to-Tail Rule)

Vectors are added graphically using the head-to-tail method. Consider walking \(4\text{ metres east}\) and then \(3\text{ metres north}\):

  1. Draw the first vector \(\vec{A} = 4\text{ m east}\).
  2. Attach the tail of the second vector \(\vec{B} = 3\text{ m north}\) directly to the head of \(\vec{A}\).
  3. Draw the resultant \(\vec{R}\) from the tail of the first vector to the head of the last vector.
Magnitude via Pythagoras' Theorem:
$$R = \sqrt{A^2 + B^2} = \sqrt{4^2 + 3^2} = \sqrt{16 + 9} = \sqrt{25} = \mathbf{5\text{ m Northeast}}$$

Important Principle: The magnitude of a resultant vector is not always the simple arithmetic sum of the individual magnitudes!

3 Parallelogram Law, Cosine Law & Direction

The Parallelogram Law: When two vectors \(\vec{A}\) and \(\vec{B}\) are placed tail-to-tail at a common origin forming two adjacent sides of a parallelogram, their resultant vector \(\vec{R}\) is represented by the main diagonal extending from that common origin.
Magnitude (Cosine Law):
$$\boxed{R = \sqrt{A^2 + B^2 + 2AB\cos\theta}}$$

Where \(\theta\) is the angle between \(\vec{A}\) and \(\vec{B}\).

Direction (Tangent / Sine Law):
$$\tan\alpha = \frac{B\sin\theta}{A + B\cos\theta} \quad \text{or} \quad \frac{R}{\sin\theta} = \frac{B}{\sin\alpha}$$

Where \(\alpha\) is the angle measured from \(\vec{A}\) toward \(\vec{R}\).

Worked Example: Applying Cosine Law & Direction

Two forces have magnitudes \(A = 6\text{ N}\) and \(B = 8\text{ N}\) separated by an angle \(\theta = 90^\circ\):

\(R = \sqrt{6^2 + 8^2 + 2(6)(8)\cos 90^\circ} = \sqrt{36 + 64 + 0} = \mathbf{10\text{ N}}\)
Direction: \(\tan\alpha = \frac{8\sin 90^\circ}{6 + 8\cos 90^\circ} = \frac{8}{6} \implies \alpha = \arctan\left(\frac{8}{6}\right) \approx \mathbf{53.1^\circ}\)

4 Three Crucial Special Cases

Orientation (\(\theta\)) Resultant Formula Worked Example
Same Direction (\(0^\circ\)) \(R = A + B\) (Maximum) \(5\text{ N east} + 3\text{ N east} = \mathbf{8\text{ N east}}\)
Opposite Directions (\(180^\circ\)) \(R = |A - B|\) (Minimum) \(10\text{ N east} + 4\text{ N west} = \mathbf{6\text{ N east}}\)
Perpendicular (\(90^\circ\)) \(R = \sqrt{A^2 + B^2}\) \(3\text{ N east} + 4\text{ N north} = \mathbf{5\text{ N NE}}\)
