Argument & Polar Form of Complex Numbers

Modulus-Angle Coordinate Systems, Quadrant Reference Angles, and Principal Arguments

1 The Argument of a Complex Number

Every non-zero complex number \(z = x + iy\) corresponds to a position vector directed from the origin \((0, 0)\) to the point \((x, y)\). The orientation of this vector is quantified by its argument.

Definition:

The argument of \(z\), denoted \(\theta\) or \(\arg(z)\), is the directed angle measured counterclockwise from the positive real axis to the vector representing \(z\).

$$\boxed{\tan\theta = \frac{y}{x} \implies \theta = \arctan\left(\frac{y}{x}\right)}$$
Figure 1: Geometric Definition of the Argument Angle \(\theta\)
Concrete Example: For \(z = 1 + i\), \(\tan\theta = \frac{1}{1} = 1\). Because \((1, 1)\) is in the first quadrant: \(\theta = 45^\circ = \frac{\pi}{4}\text{ rad}\)

2 Quadrant Analysis & Reference Angles

The Quadrant Trap: Evaluating \(\arctan(y/x)\) on a standard calculator yields angles restricted to \((-90^\circ, 90^\circ)\). You must inspect the individual algebraic signs of \(x\) and \(y\) to place \(\theta\) in its true geometric quadrant.
Figure 2: The Four Planar Quadrants
Quadrant Signs (\(x, y\)) Reference Angle \(\alpha\) Principal Argument \(\theta\)
Quadrant I \(x > 0, \; y > 0\) \(\arctan|y/x|\) \(\theta = \alpha\)
Quadrant II \(x < 0, \; y > 0\) \(\arctan|y/x|\) \(\theta = \pi - \alpha\)
Quadrant III \(x < 0, \; y < 0\) \(\arctan|y/x|\) \(\theta = -(\pi - \alpha)\)
Quadrant IV \(x > 0, \; y < 0\) \(\arctan|y/x|\) \(\theta = -\alpha\)

3 The Principal Argument: \(\operatorname{Arg}(z)\)

Because a complete circle measures \(2\pi\) radians (\(360^\circ\)), adding or subtracting any integer multiple of \(2\pi\) identifies the exact same directional line. To prevent ambiguity, mathematics defines a canonical standard branch:

Standard Interval Restriction:
$$\boxed{-\pi < \operatorname{Arg}(z) \le \pi} \quad \text{or} \quad \boxed{-180^\circ < \operatorname{Arg}(z) \le 180^\circ}$$

The uppercase notation \(\operatorname{Arg}(z)\) strictly denotes this unique principal angle.

4 Polar (Trigonometric) Form

Substituting Cartesian coordinates with trigonometric projections \(x = r\cos\theta\) and \(y = r\sin\theta\) yields the polar representation:

The Polar Representation Formula:
$$\boxed{z = r(\cos\theta + i\sin\theta)}$$

Where \(r = |z| = \sqrt{x^2 + y^2}\) and \(\theta = \operatorname{Arg}(z)\).

Figure 3: Geometric Relationship Between Polar \((r, \theta)\) and Rectangular \((x, y)\)

5 Standard Conversion Worked Examples

Example A: Converting \(z = 1 + i\) (Quadrant I)
Modulus: \(r = \sqrt{1^2 + 1^2} = \sqrt{2}\)
Argument: \(\tan\theta = \frac{1}{1} = 1 \implies \theta = \frac{\pi}{4}\) (Quadrant I)
\(\mathbf{z = \sqrt{2}\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right)}\)
Example B: Converting \(z = 3 - 3i\) (Quadrant IV)
Modulus: \(r = \sqrt{3^2 + (-3)^2} = \sqrt{18} = 3\sqrt{2}\)
Reference angle: \(\alpha = \arctan|{-3}/3| = 45^\circ = \frac{\pi}{4}\)
In Quadrant IV: \(\theta = -\alpha = -\frac{\pi}{4}\)
\(\mathbf{z = 3\sqrt{2}\left(\cos\left(-\frac{\pi}{4}\right) + i\sin\left(-\frac{\pi}{4}\right)\right)}\)
Example C: Polar Back to Rectangular

Convert \(z = 2\left(\cos\frac{\pi}{3} + i\sin\frac{\pi}{3}\right)\) into \(x + iy\):

Evaluate trig values: \(\cos\frac{\pi}{3} = \frac{1}{2}, \quad \sin\frac{\pi}{3} = \frac{\sqrt{3}}{2}\)
Multiply by \(r = 2\): \(z = 2\left(\frac{1}{2} + i\frac{\sqrt{3}}{2}\right) = 1 + \sqrt{3}i\)
\(\mathbf{z = 1 + \sqrt{3}i}\)

6 Challenging Examination Worked Examples

Advanced Example 1: Quadrant III Polar Representation Quadrant III

Express the complex number \(z = -\sqrt{3} - i\) in canonical polar form using its principal argument.

Step 1: Compute Modulus:
\(r = \sqrt{(-\sqrt{3})^2 + (-1)^2} = \sqrt{3 + 1} = \sqrt{4} = \mathbf{2}\)
Step 2: Reference Angle:
\(\alpha = \arctan\left|\frac{-1}{-\sqrt{3}}\right| = \arctan\left(\frac{1}{\sqrt{3}}\right) = \frac{\pi}{6} \; (30^\circ)\)
Step 3: Determine Quadrant & Principal Argument:
Since \(x < 0\) and \(y < 0\), \(z\) is located in Quadrant III.
\(\theta = -(\pi - \alpha) = -\left(\pi - \frac{\pi}{6}\right) = -\frac{5\pi}{6} \; (-150^\circ)\)
Step 4: Canonical Polar Form:
\(\mathbf{z = 2\left(\cos\left(-\frac{5\pi}{6}\right) + i\sin\left(-\frac{5\pi}{6}\right)\right)}\)
Advanced Example 2: Polar Form of a Complex Quotient Quotient Conversion

Convert the rational expression \(z = \frac{-4}{1 + i\sqrt{3}}\) directly into polar form.

Method (Algebraic Realization):
Multiply numerator and denominator by conjugate \((1 - i\sqrt{3})\):
\(z = \frac{-4(1 - i\sqrt{3})}{(1 + i\sqrt{3})(1 - i\sqrt{3})} = \frac{-4 + 4i\sqrt{3}}{1^2 + (\sqrt{3})^2} = \frac{-4 + 4i\sqrt{3}}{4} = -1 + i\sqrt{3}\)
Determine Modulus & Argument of \(-1 + i\sqrt{3}\):
• \(r = \sqrt{(-1)^2 + (\sqrt{3})^2} = \sqrt{1 + 3} = \mathbf{2}\)
• \(\alpha = \arctan|\sqrt{3}/(-1)| = \arctan(\sqrt{3}) = \frac{\pi}{3}\)
In Quadrant II (\(x<0, y>0\)): \(\theta = \pi - \frac{\pi}{3} = \mathbf{\frac{2\pi}{3}}\)
\(\mathbf{z = 2\left(\cos\frac{2\pi}{3} + i\sin\frac{2\pi}{3}\right)}\)
