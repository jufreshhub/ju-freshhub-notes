Conjugate, Modulus and Inverses

Geometric Reflections, Euclidean Norms, Additive Inverses, and Reciprocals

1 Conjugate of a Complex Number

The complex conjugate of a number \(z = x + iy\) is formed by negating the sign of its imaginary component while leaving the real component unchanged.

Definition & Coordinate Notation:
$$\boxed{z = x + iy \quad \Longleftrightarrow \quad \bar{z} = x - iy}$$

Geometrically, mapping \(z(x, y) \to \bar{z}(x, -y)\) represents a reflection across the real horizontal axis.

Figure 1: Conjugate as Axis Reflection on the Argand Plane
Complex Number \(z\) Conjugate \(\bar{z}\) Transformation Behavior
\(2 + 3i\) \(2 - 3i\) Imaginary sign switches \(+\to-\)
\(5 - 7i\) \(5 + 7i\) Imaginary sign switches \(-\to+\)
\(-3 + 4i\) \(-3 - 4i\) Real part stays negative; imag switches
\(4 \quad (\text{Purely Real})\) \(4\) Unchanged (\(z = \bar{z} \iff z \in \mathbb{R}\))
\(-6i \quad (\text{Purely Imag})\) \(6i\) Purely imaginary flips sign completely
Why the Conjugate is Essential (Real Product Identity):

Multiplying any complex number by its conjugate eliminates all imaginary terms, producing a strictly non-negative real scalar:

$$(x + iy)(x - iy) = x^2 - (iy)^2 = x^2 - i^2 y^2 = x^2 + y^2$$
$$\boxed{z\bar{z} = |z|^2}$$

Example: \((3 + 4i)(3 - 4i) = 3^2 + 4^2 = 9 + 16 = 25\).

2 Modulus (Norm / Absolute Value)

The modulus (or absolute value) of \(z = x + iy\), denoted \(|z|\), represents the straight-line Euclidean distance from the origin \((0, 0)\) to the coordinate point \((x, y)\) on the Argand plane.

Pythagorean Metric Formula:
$$\boxed{|z| = \sqrt{x^2 + y^2}}$$

Because it measures physical Euclidean distance, \(|z| \ge 0\) for all \(z \in \mathbb{C}\), with \(|z| = 0 \iff z = 0\).

Figure 2: Geometric Representation of the Modulus via Pythagoras
Example A: Positive Components

Find \(|z|\) for \(z = 3 + 4i\):

\(|z| = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = \mathbf{5}\)
Example B: Negative Component Warning

Find \(|z|\) for \(z = 3 - 4i\):

\(|z| = \sqrt{3^2 + (-4)^2} = \sqrt{9 + 16} = \mathbf{5}\)

Squaring negative numbers always yields positive squares!

The Five Core Properties of Modulus:
Property Mathematical Identity Pedagogical Meaning
1. Conjugate Equality \(|\bar{z}| = |z| = |-z|\) Reflections preserve origin distance
2. Modulus Squared \(|z|^2 = z\bar{z}\) Relates modulus directly to conjugate
3. Product Property \(|z_1 z_2| = |z_1||z_2|\) Modulus of product equals product of moduli
4. Quotient Property \(\left|\frac{z_1}{z_2}\right| = \frac{|z_1|}{|z_2|} \quad (z_2 \ne 0)\) Modulus distributes over division
5. Triangle Inequality \(|z_1 + z_2| \le |z_1| + |z_2|\) Straight line distance is the shortest path

3 Additive Inverse (\(-z\))

Definition:

The unique number \(-z\) that yields the additive identity \(0\) when added to \(z\):

$$\boxed{-z = -x - iy}$$

Memory Rule: Change BOTH signs (both real and imaginary parts flip signs).

Example:

For \(z = 3 + 4i\), the additive inverse is: \(-z = -3 - 4i\).

Verification: \((3 + 4i) + (-3 - 4i) = (3 - 3) + (4 - 4)i = 0 + 0i = 0\).

4 Multiplicative Inverse (Reciprocal, \(z^{-1}\))

The multiplicative inverse \(z^{-1} = \frac{1}{z}\) exists for every non-zero complex number (\(z \ne 0\)) and satisfies \(z \cdot z^{-1} = 1\).

Derivation via Complex Conjugate:
$$z^{-1} = \frac{1}{z} = \frac{\bar{z}}{z\bar{z}} = \frac{x - iy}{x^2 + y^2}$$
$$\boxed{z^{-1} = \frac{x}{x^2 + y^2} - i\frac{y}{x^2 + y^2}}$$
Worked Example: Inverses of \(z = 3 + 4i\)
Calculate denominator: \(x^2 + y^2 = 3^2 + 4^2 = 9 + 16 = 25\)
Form conjugate in numerator: \(\bar{z} = 3 - 4i\)
\(z^{-1} = \frac{3 - 4i}{25} = \mathbf{\frac{3}{25} - \frac{4}{25}i}\)

Verification: \((3 + 4i)\left(\frac{3 - 4i}{25}\right) = \frac{9 + 16}{25} = \frac{25}{25} = 1\).

5 Diagnostic Comparison: The Core Metrics Compared

Concept Action Rule Evaluation for \(z = 3 + 4i\)
Conjugate (\(\bar{z}\)) Change imaginary sign only \(3 - 4i\)
Additive Inverse (\(-z\)) Change both signs (\(-x - iy\)) \(-3 - 4i\)
Multiplicative Inverse (\(z^{-1}\)) Divide conjugate by \(x^2 + y^2\) \(\frac{3}{25} - \frac{4}{25}i\)
Modulus (\(|z|\)) Compute Euclidean distance \(\sqrt{x^2+y^2}\) \(5\)
