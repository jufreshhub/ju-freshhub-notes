Evaluating Arguments

Factual vs. Inferential Claims, Deductive Validity & Soundness, and Inductive Strength & Cogency

1 Two Fundamental Claims in Evaluating Any Argument

To evaluate whether an argument (such as “All medical students are intelligent; Hana is a medical student; therefore Hana is intelligent”) should be accepted, we test two claims—always evaluating the inferential claim first, then checking factual truth:

1st Check: Inferential Claim (“Does the reasoning work?”)

Do the premises logically support the conclusion? In “All birds are mammals; all chickens are birds → all chickens are mammals,” the reasoning is valid even though Premise 1 is false.

2nd Check: Factual Claim (“Are premises true?”)

Do the premises state actual facts? Only after reasoning passes do we verify factual truth.

2 Evaluating Deductive Arguments: Validity & Soundness

Validity vs. Invalidity (All-or-Nothing Logical Guarantee)

Valid: Assuming premises are true, conclusion cannot be false (All humans mortal; Abebe human → Abebe mortal). Invalid: Premises could be true while conclusion is false (All philosophers rational; Socrates rational → Socrates philosopher—being rational doesn't force one to be a philosopher). There is no middle ground!

Sound = Valid + All True Premises

Ex: All humans mortal (T); Hana human (T) → Hana mortal (T) = Sound.

Unsound = Invalid OR ≥1 False Premise

Ex: All birds mammals (F) → chickens mammals = Valid yet Unsound. Every invalid argument is unsound, but not every unsound argument is invalid.

3 Evaluating Inductive Arguments: Strength & Cogency

Strength vs. Weakness (Admits Degrees!)

Strong: Assuming premises true, conclusion is probably true (80 random tasty apples out of 100 → probably all 100 tasty). Weak: Conclusion is insufficiently probable (only 3 out of 100). Unlike validity, strength admits degrees (3 → 30 → 80). Rule: True premises + false conclusion = must be weak!

Cogent = Strong + True Premises + Total Evidence

Must be strong, have true premises, AND must not overlook important contrary evidence (e.g., “Most passed → Hana probably passed” fails cogency if we ignore that Hana was absent!). Ex: Reliable weather data predicting rain.

Uncogent = Weak OR ≥1 False Premise

Even strong reasoning becomes uncogent if a premise is false (e.g., assuming “Every student passed” when false) or key counter-evidence is ignored.

Worked Example A (Dawit)

All humans are mortal; Dawit is human → Dawit is mortal.
Evaluation: Deductive → Valid → True premises → Sound.

Worked Example B (Hana)

90/100 random students passed; Hana is in that class → Hana probably passed.
Evaluation: Inductive → Strong → True premises (no contrary evidence) → Cogent.
