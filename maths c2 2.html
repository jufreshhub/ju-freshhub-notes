Mathematical Induction & Well-Ordering

Universal Deductive Proofs on Natural Numbers and the Least Element Principle

1 The Foundation of Mathematical Induction

Mathematical induction is a formal method of mathematical proof used to establish that a given proposition or formula \(P(n)\) holds true for every natural number \(n \in \mathbb{N}\).

Why Not Test Individually? Suppose we propose that \(1 + 2 + \dots + n = \frac{n(n+1)}{2}\). Testing cases such as \(n=1\), \(n=2\), or \(n=100\) provides empirical evidence, but natural numbers are infinite. An infinite sequence of numbers can never be verified one by one. Induction bridges this gap by proving truth universally through logical causality.
The Classic Domino Analogy:

Imagine an endless line of dominoes standing in order. To knock every domino down, two conditions must be met:

  • Initial Action: The first domino must be knocked over (Base Step).
  • Chain Reaction: The spacing must guarantee that whenever the \(k\)-th domino falls, it inevitably knocks down the \((k+1)\)-th domino (Inductive Step).

Result: By deductive progression, every single domino in the infinite chain falls down.

2 The Three Formal Steps of Induction

Step 1: Base Case (Anchor Step)

Verify \(n = 1\)

Verify directly that the proposition \(P(n)\) is true for the first natural number, typically \(n = 1\). This establishes that the initial domino falls.

Step 2: Induction Hypothesis

Assume for \(n = k\)

Assume that the proposition holds true for an arbitrary natural number \(k \ge 1\). We write out the statement \(P(k)\) and treat it as a trusted algebraic tool for the next step.

Step 3: Induction Step (Deductive Leap)

Prove for \(n = k + 1\)

Using the hypothesis \(P(k)\), prove rigorously that \(P(k+1)\) is true. This demonstrates that if the \(k\)-th domino falls, it must knock down the \((k+1)\)-th domino.

Vital Examination Logic: We never assume that the theorem is true for all numbers in advance. We assume truth only for a specific intermediate value \(k\), and leverage that single assumption to deduce truth for the consecutive successor \(k+1\).

3 Worked Proof: Sum of the First \(n\) Natural Numbers

Proposition: Prove that for every natural number \(n \in \mathbb{N}\): $$1 + 2 + 3 + \dots + n = \frac{n(n + 1)}{2}$$
Step 1: Base Case (\(n = 1\))
  • \(\text{LHS} = 1\)
  • \(\text{RHS} = \frac{1(1 + 1)}{2} = \frac{2}{2} = 1\)

Since \(\text{LHS} = \text{RHS} = 1\), the base case holds true.

Step 2: Induction Hypothesis

Assume the identity holds for \(n = k\):

$$1 + 2 + 3 + \dots + k = \frac{k(k + 1)}{2}$$
Step 3: Induction Step (\(n = k + 1\))

We must show that substituting \(n = k + 1\) yields the target expression:

$$\text{Target: } 1 + 2 + \dots + k + (k + 1) = \frac{(k + 1)((k + 1) + 1)}{2} = \frac{(k + 1)(k + 2)}{2}$$

Evaluate the left-hand side and apply the induction hypothesis:

\(\underbrace{1 + 2 + \dots + k}_{\text{Replace by Hypothesis}} + (k + 1) = \frac{k(k + 1)}{2} + (k + 1)\)
Find common denominator: \(= \frac{k(k + 1) + 2(k + 1)}{2}\)
Factor out \((k + 1)\): \(= \frac{(k + 1)(k + 2)}{2}\)

The left side reduces exactly to the target. Thus, \(P(k+1)\) is true whenever \(P(k)\) is true.

By the Principle of Mathematical Induction, the formula is universally valid for all \(n \in \mathbb{N}\).

4 Worked Proof: Sum of the First \(n\) Odd Numbers

Proposition: Prove that for every natural number \(n \in \mathbb{N}\): $$1 + 3 + 5 + \dots + (2n - 1) = n^2$$
\(n\) Sum of Odd Numbers Value Perfect Square (\(n^2\))
1 \(1\) 1 \(1^2 = 1\)
2 \(1 + 3\) 4 \(2^2 = 4\)
3 \(1 + 3 + 5\) 9 \(3^2 = 9\)
4 \(1 + 3 + 5 + 7\) 16 \(4^2 = 16\)
Induction Hypothesis:

Assume truth for \(n = k\):

$$1 + 3 + 5 + \dots + (2k - 1) = k^2$$
Inductive Step for \(n = k + 1\):

The \((k+1)\)-th odd integer is \(2(k + 1) - 1 = 2k + 1\). Adding it to the left side:

\(\underbrace{1 + 3 + \dots + (2k - 1)}_{\text{Hypothesis } = k^2} + (2k + 1) = k^2 + (2k + 1)\)
Recognize the binomial expansion: \(= k^2 + 2k + 1 = (k + 1)^2\)

This matches the required form \((k+1)^2\). The theorem is established for all \(n \in \mathbb{N}\).

5 The Well-Ordering Principle (WOP)

Axiom Statement:

Every non-empty subset of the set of natural numbers \(\mathbb{N}\) contains a smallest (least) element.

$$\forall S \subseteq \mathbb{N},\; (S \neq \emptyset \implies \exists m \in S \text{ such that } \forall x \in S,\, m \le x)$$
Example A: Finite Subset

\(A = \{18, 21, 19, 25, 23\}\)

Smallest element: \(\min(A) = 18 \in A\).

Example B: Infinite Subset

\(B = \{5, 8, 12, 20, \dots\}\)

Smallest element: \(\min(B) = 5 \in B\).

Crucial Counterexample (Real Numbers):

The Well-Ordering Principle is a foundational property of discrete sets like \(\mathbb{N}\), and does not apply generally to real numbers (\(\mathbb{R}\)).

Consider the open set of positive real numbers: \(S = \{x \in \mathbb{R} \mid x > 0\} = (0, \infty)\).

There is no smallest number in \(S\). If one proposes \(\epsilon > 0\), the smaller value \(\frac{\epsilon}{2} \in S\) immediately contradicts it. Hence, the Well-Ordering Principle strictly requires the domain of natural numbers.

6 Comparison: Mathematical Induction vs. Well-Ordering

Feature Mathematical Induction Well-Ordering Principle
Primary Purpose Deductive method to prove theorems for all \(n \in \mathbb{N}\) Structural axiom characterizing the set \(\mathbb{N}\)
Mechanism Base case \(P(1)\) and recursive bridge \(P(k) \implies P(k+1)\) Guarantees existence of a minimum element in any \(\emptyset \neq S \subseteq \mathbb{N}\)
Mental Model Falling dominoes chain Identifying the minimum starting element
Equivalence In axiomatic set theory (Peano axioms), Mathematical Induction and the Well-Ordering Principle are mathematically equivalent.
