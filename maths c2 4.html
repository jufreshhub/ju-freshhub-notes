Number Systems · Fractional Arithmetic

The Set of Rational Numbers

Quotients, Field Properties, Decimal Expansions, and Foundations of Irrationals

1 Motivation & Definition of \(\mathbb{Q}\)

While the integers \(\mathbb{Z}\) accommodate addition, subtraction, and multiplication, they cannot solve simple linear equations requiring exact division.

The Division Dilemma: Consider the linear equation: $$2x + 1 = 0 \implies 2x = -1 \implies x = -\frac{1}{2}$$ Because \(-\frac{1}{2} \notin \mathbb{Z}\), a broader algebraic system is required to achieve division closure.
Formal Definition: A rational number is any number expressible as the quotient of two integers with a non-zero denominator: $$\mathbb{Q} = \left\{ \frac{a}{b} \;\middle|\; a, b \in \mathbb{Z} \text{ and } b \neq 0 \right\}$$ The symbol \(\mathbb{Q}\) denotes Quotient.
Anatomy of a Fraction
$$\frac{a \leftarrow \text{Numerator}}{b \leftarrow \text{Denominator } (b \neq 0)}$$

The denominator can never equal zero, as division by zero is undefined.

Integers are Rational Numbers

Every integer \(n\) is expressed as a fraction with denominator \(1\):

\(5 = \frac{5}{1}, \quad 0 = \frac{0}{1}, \quad -4 = \frac{-4}{1}\)

Hence: \(\mathbb{N} \subset \mathbb{W} \subset \mathbb{Z} \subset \mathbb{Q}\).

Lowest Form (Irreducible Fraction):

A fraction \(\frac{a}{b}\) is in lowest form when \(a\) and \(b\) share no common factors other than \(1\), meaning \(\gcd(a, b) = 1\).

$$\frac{12}{18} = \frac{12 \div 6}{18 \div 6} = \frac{2}{3} \quad (\text{since } \gcd(2, 3) = 1)$$

2 Fundamental Operations on \(\mathbb{Q}\)

The set of rational numbers forms a mathematical field, meaning it is closed under addition, subtraction, multiplication, and non-zero division:

A. Addition \((+)\) Common Denominator
$$\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}$$

Example: \(\frac{1}{2} + \frac{3}{5} = \frac{1(5) + 3(2)}{2(5)} = \frac{5 + 6}{10} = \mathbf{\frac{11}{10}}\)

Common Error: Never add across! \(\frac{1}{2} + \frac{3}{5} \neq \frac{4}{7}\).

B. Subtraction \((-)\) Additive Inverse
$$\frac{a}{b} - \frac{c}{d} = \frac{ad - bc}{bd}$$

Example: \(\frac{1}{2} - \frac{3}{5} = \frac{1(5) - 3(2)}{10} = \frac{5 - 6}{10} = \mathbf{-\frac{1}{10}}\)

C. Multiplication \((\times)\) Direct Product
$$\frac{a}{b} \times \frac{c}{d} = \frac{ac}{bd}$$

Example: \(\frac{1}{2} \times \frac{3}{5} = \frac{1 \times 3}{2 \times 5} = \mathbf{\frac{3}{10}}\)

D. Division \((\div)\) Keep-Change-Flip
$$\frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \times \frac{d}{c} = \frac{ad}{bc} \quad (c \neq 0)$$

Example: \(\frac{1}{2} \div \frac{3}{5} = \frac{1}{2} \times \frac{5}{3} = \mathbf{\frac{5}{6}}\)

3 Field Properties of Rational Numbers

Property Formal Meaning Concrete Example
Closure \(a+b \in \mathbb{Q},\; a \times b \in \mathbb{Q}\) \(\frac{1}{2} + \frac{1}{3} = \frac{5}{6} \in \mathbb{Q}\)
Commutative \(a+b = b+a,\; ab = ba\) \(\frac{1}{3} \times \frac{2}{5} = \frac{2}{5} \times \frac{1}{3} = \frac{2}{15}\)
Associative \((a+b)+c = a+(b+c)\) \((\frac{1}{2} + \frac{1}{4}) + \frac{1}{4} = \frac{1}{2} + (\frac{1}{4} + \frac{1}{4}) = 1\)
Additive Identity \(a + 0 = a\) \(\frac{3}{7} + 0 = \frac{3}{7}\)
Additive Inverse \(a + (-a) = 0\) \(\frac{4}{5} + \left(-\frac{4}{5}\right) = 0\)
Multiplicative Identity \(a \times 1 = a\) \(-\frac{2}{9} \times 1 = -\frac{2}{9}\)
Multiplicative Inverse \(a \times \frac{1}{a} = 1 \quad (\forall a \neq 0)\) \(\frac{2}{3} \times \frac{3}{2} = 1\)
Critical Examination Fact: Every rational number has an additive inverse. However, only non-zero rational numbers possess a multiplicative inverse (reciprocal). Zero has no reciprocal because \(\frac{1}{0}\) is undefined.

4 Order Relations in \(\mathbb{Q}\)

To compare rational numbers, convert them to a common denominator or compare decimal values (e.g., \(\frac{3}{4} = 0.75 > \frac{1}{2} = 0.50\)). Four axioms dictate their ordering:

1. Transitive Property: If \(a > b\) and \(b > c\), then \(a > c\).
2. Addition Property: If \(a > b\), then \(a + c > b + c\) for any rational \(c\).
3. Multiplication Property:

Multiplying by \(c > 0\) preserves order: \(a > b \implies ac > bc\).

Multiplying by \(c < 0\) reverses order: \(\frac{1}{2} > \frac{1}{4} \xrightarrow{\times (-2)} -1 < -\frac{1}{2}\).

4. Law of Trichotomy: For any \(a, b \in \mathbb{Q}\), exactly one statement holds: \(a > b\), \(a < b\), or \(a = b\).

5 Decimal Representation of Rational Numbers

Every rational number can be expressed as either a terminating decimal or a non-terminating periodic (repeating) decimal.

A. Terminating Decimals

Decimals that end after a finite number of decimal digits.

\(\frac{25}{4} = 6.25\)
\(0.25 = \frac{25}{100} = \frac{1}{4}\)
\(3.47 = \frac{347}{100}\)
B. Non-Terminating Periodic Decimals

Decimals that continue infinitely but exhibit a repeating block of digits.

\(\frac{25}{3} = 8.3333\dots = 8.\overline{3}\)
\(\frac{3}{11} = 0.272727\dots = 0.\overline{27}\)
Standard Conversion Algorithm: Repeating Decimal to Fraction

To convert \(x = 0.3333\dots\) into its exact fractional representation:

Let \(x = 0.3333\dots\) \(\quad\) (Equation 1)
Multiply by \(10\): \(10x = 3.3333\dots\) \(\quad\) (Equation 2)
Subtract Eq 1 from Eq 2: \(10x - x = 3.3333\dots - 0.3333\dots\)
\(9x = 3 \implies x = \frac{3}{9} = \mathbf{\frac{1}{3}}\)

Conclusion: Even though the decimal is infinite, its repeating periodicity guarantees that it is rational.

6 What is NOT Rational? (Irrational Numbers)

Decimals that are non-terminating and non-periodic cannot be represented as the ratio of two integers. These form the set of irrational numbers.

\(\sqrt{2} = 1.41421356\dots \quad\) (infinite, no repeating pattern)
\(\pi = 3.14159265\dots \quad\) (infinite, no repeating pattern)
Decimal Classification Representative Example Number Set Classification
Terminating Decimal \(0.5, \; 2.75, \; 6.25\) Rational (\(\mathbb{Q}\))
Non-Terminating Periodic (Repeating) \(0.333\dots, \; 0.2727\dots\) Rational (\(\mathbb{Q}\))
Non-Terminating & Non-Periodic \(\sqrt{2}, \; \sqrt{5}, \; \pi\) Irrational (\(\mathbb{I}\) or \(\mathbb{R} \setminus \mathbb{Q}\))
