The Set of Real Numbers

The Real Continuum, Algebraic Field Axioms, Order Relations, and Geometric Line Duality

1 Definition & Structural Hierarchy of \(\mathbb{R}\)

The real number system unites all numbers that can measure continuous physical quantities. Every real number is either rational or irrational.

Set-Theoretic Definition: The set of real numbers, denoted by \(\mathbb{R}\), is the disjoint union of the set of rational numbers \(\mathbb{Q}\) and the set of irrational numbers \(\mathbb{I}\): $$\mathbb{R} = \mathbb{Q} \cup \mathbb{I} \quad \text{where} \quad \mathbb{Q} \cap \mathbb{I} = \emptyset$$
Category Core Definition Representative Elements
Rational Numbers (\(\mathbb{Q}\)) Expressible as \(\frac{a}{b}\) (\(a, b \in \mathbb{Z}, b \neq 0\)); terminating or repeating decimals. \(-4, \; 0, \; \frac{3}{5}, \; 0.25, \; 0.\overline{3}\)
Irrational Numbers (\(\mathbb{I}\)) Cannot be written as \(\frac{a}{b}\); non-terminating and non-periodic decimals. \(\sqrt{2}, \; \sqrt{7}, \; \pi, \; e, \; 1.4142\dots\)
The Universal Set Inclusion Chain:
$$\mathbb{N} \subset \mathbb{W} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$$
  • Every natural number is an integer (\(\mathbb{N} \subset \mathbb{Z}\)).
  • Every integer is a rational number (\(\mathbb{Z} \subset \mathbb{Q}\), since \(z = \frac{z}{1}\)).
  • Every rational number is a real number (\(\mathbb{Q} \subset \mathbb{R}\)).
  • Asymmetric Truth: The converse does not hold! For example, \(\sqrt{3}\) is a real number, but it is strictly not rational.

2 Operations & Field Properties of \(\mathbb{R}\)

Operation Algebraic Form Concrete Example Closure Status
Addition \((+)\) \(a + b\) \(\sqrt{2} + \sqrt{3} \approx 3.14626\dots\) Closed in \(\mathbb{R}\)
Subtraction \((-)\) \(a - b\) \(5.4 - \pi \approx 2.2584\dots\) Closed in \(\mathbb{R}\)
Multiplication \((\times)\) \(a \times b\) \(\sqrt{2} \times \sqrt{3} = \sqrt{6}\) Closed in \(\mathbb{R}\)
Division \((\div)\) \(\frac{a}{b} \quad (b \neq 0)\) \(\frac{\sqrt{8}}{\sqrt{2}} = \sqrt{4} = 2\) Closed for \(b \neq 0\)

The Seven Foundational Field Axioms:

Property General Formula Concrete Example
1. Closure \(a + b \in \mathbb{R},\; ab \in \mathbb{R}\) \(\pi + 2 \in \mathbb{R},\; \sqrt{5} \times \sqrt{5} = 5 \in \mathbb{R}\)
2. Commutative \(a + b = b + a,\; ab = ba\) \(\sqrt{2} + 3 = 3 + \sqrt{2}\)
3. Associative \((a + b) + c = a + (b + c)\) \((\sqrt{3} + 1) + 4 = \sqrt{3} + (1 + 4)\)
4. Additive Identity \(a + 0 = 0 + a = a\) \(\pi + 0 = \pi \quad (0 \text{ is identity})\)
5. Additive Inverse \(a + (-a) = 0\) \(\sqrt{7} + (-\sqrt{7}) = 0\)
6. Multiplicative Identity \(a \times 1 = 1 \times a = a\) \(\sqrt{11} \times 1 = \sqrt{11} \quad (1 \text{ is identity})\)
7. Multiplicative Inverse \(a \times \frac{1}{a} = 1 \quad (\forall a \neq 0)\) \(\sqrt{5} \times \frac{1}{\sqrt{5}} = 1\)
Vital Inverse Distinction: Every real number possesses an additive inverse (including zero, where \(-0 = 0\)). However, zero has no multiplicative inverse because the expression \(\frac{1}{0}\) is mathematically undefined.

3 The Real Number Line & Geometric Duality

The Completeness Principle (Continuum Duality): There exists an exact one-to-one (bijective) correspondence between the set of real numbers \(\mathbb{R}\) and the points on a continuous straight line. Every real number marks a distinct point, and every point denotes a unique real number.
Coordinate Structure:
  • Origin: The baseline anchor point representing \(0\).
  • Positive Real Numbers: Points located to the right of \(0\) \((x > 0)\).
  • Negative Real Numbers: Points located to the left of \(0\) \((x < 0)\).
Geometric Ordering Principle:

A real number \(a\) is strictly greater than \(b\) \((a > b)\) if and only if \(a\) is positioned to the right of \(b\) on the line:

\(5 > 2 \quad (5 \text{ is to the right of } 2)\)
\(-2 > -5 \quad (-2 \text{ is closer to } 0 \text{ and to the right of } -5)\)

4 Order Relations & Inequality Axioms in \(\mathbb{R}\)

A. Transitive Property: If \(a > b\) and \(b > c\), then \(a > c\). (e.g., \(\pi > 3\) and \(3 > e \implies \pi > e\)).
B. Addition Property: Adding any real number \(c\) preserves the inequality: \(a > b \implies a + c > b + c\).
C. Multiplication Property (Sign Reversal Criterion):
  • Multiplying by \(c > 0\): \(a > b \implies ac > bc\).
  • Multiplying by \(c < 0\): Reverses direction: \(5 > 2 \xrightarrow{\times (-3)} -15 < -6\).
D. Law of Trichotomy: For any two real numbers \(a, b \in \mathbb{R}\), exactly one of three relations holds: \(a > b\), \(a < b\), or \(a = b\).

5 Comprehensive Step-by-Step Worked Examples

Example 1: Classifying Numbers in the Number Hierarchy Classification

Determine the most restrictive subset (\(\mathbb{N}, \mathbb{Z}, \mathbb{Q}, \text{or } \mathbb{I}\)) and verify membership in \(\mathbb{R}\) for: \(A = -7, \quad B = \sqrt{16}, \quad C = \sqrt{11}, \quad D = \frac{22}{7}, \quad E = 0.\overline{45}\).

• \(A = -7 \implies \mathbf{\mathbb{Z}} \text{ (Integer, also in } \mathbb{Q} \text{ and } \mathbb{R})\)
• \(B = \sqrt{16} = 4 \implies \mathbf{\mathbb{N}} \text{ (Natural Number, hence also in } \mathbb{Z}, \mathbb{Q}, \mathbb{R})\)
• \(C = \sqrt{11} \approx 3.3166\dots \implies \mathbf{\mathbb{I}} \text{ (Irrational, Non-terminating & non-periodic, in } \mathbb{R})\)
• \(D = \frac{22}{7} \implies \mathbf{\mathbb{Q}} \text{ (Rational, explicit quotient of integers, in } \mathbb{R})\)
• \(E = 0.\overline{45} = \frac{45}{99} = \frac{5}{11} \implies \mathbf{\mathbb{Q}} \text{ (Repeating decimal, hence rational, in } \mathbb{R})\)

Result: All five values belong unconditionally to the set of real numbers \(\mathbb{R}\).

Example 2: Arithmetic Operations with Irrational Numbers Field Closure

Evaluate the expressions and observe whether the result is rational or irrational, confirming closure in \(\mathbb{R}\):

Part (a): Addition
\((3 + \sqrt{5}) + (2 - \sqrt{5}) = (3 + 2) + (\sqrt{5} - \sqrt{5}) = 5 + 0 = \mathbf{5} \in \mathbb{Q} \subset \mathbb{R}\)
Part (b): Conjugate Multiplication (Difference of Squares)
\((2 + \sqrt{3})(2 - \sqrt{3}) = (2)^2 - (\sqrt{3})^2 = 4 - 3 = \mathbf{1} \in \mathbb{Q} \subset \mathbb{R}\)

Key Insight: Adding or multiplying two irrational numbers may yield a rational number, but the result is always guaranteed to be a real number.

Example 3: Solving Inequalities Involving Negative Factors Order Relations

Find the complete solution set in \(\mathbb{R}\) for the linear inequality: \(-3x + 7 < 22\).

Step 1: Subtract \(7\) from both sides:
\(-3x + 7 - 7 < 22 - 7 \implies -3x < 15\)
Step 2: Divide both sides by \(-3\) (REVERSE the inequality sign!):
\(x > \frac{15}{-3} \implies \mathbf{x > -5}\)
Interval notation: \(\mathbf{(-5, \infty)}\)
