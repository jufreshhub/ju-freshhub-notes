Introduction & Plotting Complex Numbers

The Imaginary Unit \(i\), Algebraic Standard Form, Equality Axioms, and the Argand Plane

1 Motivation & The Imaginary Unit \(i\)

In the real number system \(\mathbb{R}\), the square of any real number is non-negative (\(x^2 \ge 0\)). Consequently, polynomial equations with negative discriminants have zero real solutions.

The Foundational Contradiction:
$$x^2 + 1 = 0 \implies x^2 = -1 \implies x = \pm\sqrt{-1}$$

No real number multiplied by itself produces \(-1\). To overcome this algebraic limitation, the imaginary unit, denoted by \(i\), is defined.

The Defining Identity:
$$\boxed{i^2 = -1} \quad \text{or equivalently} \quad \boxed{i = \sqrt{-1}}$$

This single axiom extends mathematical analysis beyond the one-dimensional real line into the two-dimensional complex plane.

2 Standard Algebraic Form of Complex Numbers

Formal Definition: A complex number is an expression represented in the standard canonical form:
$$\boxed{z = x + iy}$$

Where \(x, y \in \mathbb{R}\), and \(i = \sqrt{-1}\). The collection of all such expressions constitutes the set of complex numbers \(\mathbb{C}\).

Real Part: \(\operatorname{Re}(z)\)

The standalone real component that is independent of \(i\):

\(\operatorname{Re}(z) = x\)
Imaginary Part: \(\operatorname{Im}(z)\)

The real coefficient multiplying \(i\) (excluding \(i\) itself):

\(\operatorname{Im}(z) = y\)
Crucial Examination Traps:
  • Sign Inclusion: For \(z = 5 - 4i\), \(\operatorname{Re}(z) = 5\), while \(\operatorname{Im}(z) = \mathbf{-4}\) (the negative sign belongs strictly to the imaginary part).
  • Never Include \(i\): \(\operatorname{Im}(z)\) is purely the real scalar \(y\). Writing \(\operatorname{Im}(z) = -4i\) is a major algebraic error!
  • Implicit Unit: For \(z = 1 - i = 1 + (-1)i\), \(\operatorname{Re}(z) = 1\) and \(\operatorname{Im}(z) = -1\).

3 Classifications: Purely Real & Purely Imaginary

A. Purely Imaginary Numbers \(\operatorname{Re}(z) = 0\)

Occurs when the real part is strictly zero (\(x = 0\) and \(y \neq 0\)):

\(z = 5i = 0 + 5i\)
\(z = -3i = 0 + (-3)i\)
B. Purely Real Numbers \(\operatorname{Im}(z) = 0\)

Occurs when the imaginary part is strictly zero (\(y = 0\)):

\(z = 4 = 4 + 0i\)
\(z = -7 = -7 + 0i\)
Every real number is a complex number with zero imaginary part: \(\mathbb{R} \subset \mathbb{C}\).

4 Plotting on the Argand Plane (Complex Plane)

Every complex number \(z = x + iy\) corresponds bijectively to a unique ordered pair \((x, y)\) on a 2D Cartesian coordinate system termed the Argand Plane:

$$z = x + iy \quad \Longleftrightarrow \quad (x, y)$$
Horizontal Axis:

The Real Axis (\(\operatorname{Re}\)) represents the scalar value \(x\).

Vertical Axis:

The Imaginary Axis (\(\operatorname{Im}\)) represents the scalar value \(y\).

Figure 1: The Complex Argand Plane Architecture
Systematic Plotting Steps:
Case 1: Plotting \(z = 2 + 3i\) (First Quadrant)

\(x = 2, \; y = 3 \implies (2, 3)\). Shift \(2\) units right, \(3\) units up.

Case 2: Plotting \(z = -3 - 2i\) (Third Quadrant)

\(x = -3, \; y = -2 \implies (-3, -2)\). Shift \(3\) units left, \(2\) units down.

5 Axiom of Equality for Complex Numbers

Two complex numbers are mathematically identical if and only if their corresponding real components are equal AND their imaginary components are equal.

The Equality Criterion:

Let \(z_1 = a + ib\) and \(z_2 = c + id\). Then:

$$z_1 = z_2 \iff a = c \quad \text{and} \quad b = d$$
Worked Example: Solving for Unknowns

Find the real values of \(x\) and \(y\) given the identity: \(2 + xi = y + 6i\).

Equate Real Parts: \(2 = y \implies \mathbf{y = 2}\)
Equate Imaginary Parts: \(x = 6 \implies \mathbf{x = 6}\)

6 Additional Step-by-Step Worked Examples

Example 1: Identifying Components in Rational Fractions Decomposition

Find the real and imaginary parts of \(z = \frac{6 - 10i}{2}\).

Distribute the divisor: \(z = \frac{6}{2} - \frac{10}{2}i = 3 - 5i\)
• \(\operatorname{Re}(z) = 3\)  |  • \(\operatorname{Im}(z) = -5\)
Example 2: Equality with Linear Expressions System Solving

Solve for \(a, b \in \mathbb{R}\) if \((2a - 1) + 4ib = 7 - 12i\).

Equate Real Parts: \(2a - 1 = 7 \implies 2a = 8 \implies \mathbf{a = 4}\)
Equate Imaginary Parts: \(4b = -12 \implies \mathbf{b = -3}\)
