Description and Relationships of Sets

Methods of Describing Sets, Set Classification, Subsets, and Power Sets

P1 Four Methods of Describing Sets

There are four distinct mathematical methods used to describe and specify sets:

1. Verbal Method (Statement Form)

A set is described using a clear descriptive sentence in ordinary language.

  • "The set of counting numbers less than \(6\)." → Defines \(A = \{1, 2, 3, 4, 5\}\).
  • "The set of vowels in the English alphabet." → Defines \(V = \{a, e, i, o, u\}\).
  • "The set of countries in Africa."
  • "The set of positive even numbers less than \(12\)."

2. Roster (Complete Listing) Method

Every individual element of the set is explicitly listed inside curly brackets \(\{\dots\}\), separated by commas.

\[A = \{1, 2, 3, 4, 5\} \quad \text{and} \quad B = \{1, 2, 3, 4, 6, 12\}\]
Three Fundamental Rules of the Roster Method:
  1. Every member must be included in the listing.
  2. No repetition: Writing an element multiple times does not change the set: \(\{1, 1, 2, 2, 3\} = \{1, 2, 3\}\).
  3. Order does not matter: Rearranging elements leaves the set identical: \(\{1, 2, 3\} = \{3, 2, 1\}\).

3. Partial Listing Method

Used when a set contains too many elements to list completely, or infinitely many elements that follow a distinct, established pattern. An ellipsis (three dots: \(\dots\)) indicates continuation.

DescriptionPartial Listing Notation
Counting numbers (Natural numbers)\(\{1, 2, 3, 4, 5, \dots\}\)
Non-positive integers\(\{\dots, -3, -2, -1, 0\}\)
Positive multiples of \(5\)\(\{5, 10, 15, 20, \dots\}\)
Positive odd integers less than \(100\)\(\{1, 3, 5, \dots, 97, 99\}\)

4. Set-Builder Method

Instead of listing elements, a variable and a characterizing predicate (condition) that uniquely describes all members are stated.

\[A = \{x \mid x \text{ is an even positive integer less than } 10\}\]

Read as: "The set of all \(x\) such that (\(\mid\)) \(x\) is an even positive integer less than \(10\)."

Evaluating this yields \(A = \{2, 4, 6, 8\}\). (A colon \(:\) can be used interchangeably with the vertical bar \(\mid\)). Another example: \(B = \{x \in \mathbb{N} \mid x < 5\} = \{1, 2, 3, 4\}\).

Comparison of All Four Methods (Positive even integers < 10):

MethodRepresentation
VerbalThe positive even integers less than \(10\).
Roster\(\{2, 4, 6, 8\}\)
Partial ListingNot needed (the set is small and finite).
Set-Builder\(\{x \mid x \text{ is an even integer and } 0 < x < 10\}\)

P2 Empty, Finite, and Infinite Sets

5. Empty Set (Null Set)

Definition: A set containing no elements at all is called the empty set (or null set). It is symbolized by:
\[\varnothing \quad \text{or} \quad \{\}\]

Example: \(A = \{x \in \mathbb{N} \mid x < 0\}\). Since no natural number is negative, \(A = \varnothing\).

Vital Exam Distinction:
\[\varnothing \neq \{\varnothing\}\]

• \(\varnothing\) has zero elements (empty).

• \(\{\varnothing\}\) is a non-empty set with one element: namely, the empty set itself.

6. Finite vs. Infinite Sets

  • Finite Set: A set whose elements can be completely counted and matched with \(\{1, 2, \dots, n\}\) for some integer \(n \ge 0\).
    Example: \(A = \{1, 2, 3, 4\}\) (Cardinality \(|A| = 4\)).
  • Infinite Set: A set with an unlimited number of elements whose counting process never terminates.
    Example: \(\mathbb{N} = \{1, 2, 3, 4, \dots\}\) (The counting numbers continue indefinitely).

P3 Relationships Between Sets

7. Subsets

Definition: Set \(A\) is a subset of set \(B\), denoted by \(A \subseteq B\), if and only if every element of \(A\) is also an element of \(B\):
\[A \subseteq B \iff \forall x \, (x \in A \to x \in B)\]

Example: Let \(A = \{1, 2\}\) and \(B = \{1, 2, 3, 4\}\). Here, \(A \subseteq B\), but \(B \not\subseteq A\) (since \(3, 4 \in B\) but \(3, 4 \notin A\)).

Universal Subset Theorems:

For any arbitrary set \(A\):

1. \(\varnothing \subseteq A\)  (The empty set is a subset of every set).

2. \(A \subseteq A\)  (Every set is a subset of itself — reflexivity).

8. Equal Sets

Definition: Two sets \(A\) and \(B\) are equal (\(A = B\)) if and only if they contain precisely the same elements. Symbolically:
\[A = B \iff (A \subseteq B \land B \subseteq A)\]

Example: \(A = \{1, 2, 3\}\) and \(B = \{3, 2, 1, 1\}\). Since order and repetition are irrelevant, \(A = B\).

9. Equivalent Sets

Definition: Two sets \(A\) and \(B\) are equivalent (denoted \(A \sim B\)) if there exists a one-to-one correspondence (bijection) between their elements. For finite sets, this means they have the exact same number of elements (\(|A| = |B|\)).

Example: \(A = \{a, b, c\}\) and \(B = \{1, 2, 3\}\). We can match \(a \leftrightarrow 1\), \(b \leftrightarrow 2\), and \(c \leftrightarrow 3\). Thus, \(A \sim B\).

RelationshipDefining CriterionIllustrative Example
Equal Sets (\(A = B\))Identical elements\(\{1, 2\} = \{2, 1\}\)
Equivalent Sets (\(A \sim B\))Identical number of elements (\(|A| = |B|\))\(\{a, b\} \sim \{1, 2\}\)
Rule: Equal sets are always equivalent. However, equivalent sets are not necessarily equal!

10. Proper Subset

Definition: A set \(A\) is a proper subset of \(B\), denoted by \(A \subset B\), if \(A \subseteq B\) and \(A \neq B\) (every element of \(A\) is in \(B\), and \(B\) contains at least one element not in \(A\)).

Example: Let \(A = \{1, 2\}\) and \(B = \{1, 2, 3\}\). Then \(A \subset B\). But \(A \not\subset A\) because a set cannot be a proper subset of itself.

P4 Power Sets

11. What is a Power Set?

Definition: The power set of a set \(A\), denoted by \(\mathcal{P}(A)\), is the set of all subsets of \(A\):
\[\mathcal{P}(A) = \{X \mid X \subseteq A\}\]

Let \(A = \{1, 2\}\). Listing all possible subsets:

  • Subset with 0 elements: \(\varnothing\)
  • Subsets with 1 element: \(\{1\}, \{2\}\)
  • Subset with 2 elements: \(\{1, 2\}\)
\(\mathcal{P}(A) = \{\varnothing, \{1\}, \{2\}, \{1, 2\}\}\)

12. The Power-Set Counting Formulas

For any finite set \(A\) containing \(n\) elements (i.e., \(|A| = n\)):

\(\text{Total number of subsets} = 2^n\)

\(\text{Total number of proper subsets} = 2^n - 1\)

Number of Elements (\(n\))Total Subsets (\(2^n\))Proper Subsets (\(2^n - 1\))
\(0\) (\(\varnothing\))\(2^0 = 1\)\(0\)
\(1\)\(2^1 = 2\)\(1\)
\(2\)\(2^2 = 4\)\(3\)
\(3\)\(2^3 = 8\)\(7\)
\(4\)\(2^4 = 16\)\(15\)
\(5\)\(2^5 = 32\)\(31\)
\(6\)\(2^6 = 64\)\(63\)
Exam Problem Solving:

• If a set has 64 subsets, find its cardinality:
\(2^n = 64 = 2^6 \implies \mathbf{n = 6}\).

• If a set has 31 proper subsets, find its cardinality:
\(2^n - 1 = 31 \implies 2^n = 32 = 2^5 \implies \mathbf{n = 5}\).

P5 Universal Set

Definition: The universal set (denoted by \(U\)) is the fixed encompassing set that contains all elements under consideration in a specific mathematical context. All other sets in that discussion are subsets of \(U\).

Example: If we discuss integers from \(1\) to \(10\), then \(U = \{1, 2, 3, \dots, 10\}\). Then \(A = \{2, 4, 6, 8, 10\}\) is naturally a subset of \(U\).
