Unit Vectors

Cartesian Basis Vectors (\(\hat{i}, \hat{j}, \hat{k}\)), Analytical Vector Arithmetic, and Normalization

1 What is a Unit Vector?

Saying “Walk 5 metres” lacks direction, whereas “Walk 5 metres east” specifies both distance and direction. Often in physics, we wish to isolate and communicate pure direction alone, independent of physical size or units.

Definition:

A unit vector is a dimensionless vector whose magnitude is strictly equal to \(1\) and whose sole purpose is to specify spatial direction. It is denoted by a letter topped with a circumflex (hat):

$$\boxed{\hat{A}} \qquad \text{with} \qquad \boxed{|\hat{A}| = 1}$$
Figure 1: Scaling a Vector into its Unit Vector
Magnitude & Unit Contrast:
• A displacement of \(10\text{ m east}\) has magnitude \(10\text{ m}\).
• A unit vector pointing east has magnitude \(1\) and no physical unit.

2 The Three Cartesian Basis Unit Vectors

Figure 2: Orthogonal 3D Coordinate Basis (\(\hat{i}, \hat{j}, \hat{k}\))
Unit Vector Directional Axis Magnitude
\(\hat{i}\) Points along positive \(x\)-axis \(|\hat{i}| = 1\)
\(\hat{j}\) Points along positive \(y\)-axis \(|\hat{j}| = 1\)
\(\hat{k}\) Points along positive \(z\)-axis \(|\hat{k}| = 1\)

3 Expressing Vectors in Unit-Vector Notation

Two Dimensions (2D)
$$\vec{A} = A_x\hat{i} + A_y\hat{j}$$
Three Dimensions (3D)
$$\vec{A} = A_x\hat{i} + A_y\hat{j} + A_z\hat{k}$$
Examples:
• Given \(A_x = 3,\; A_y = 4,\; A_z = 5 \implies \mathbf{\vec{A} = 3\hat{i} + 4\hat{j} + 5\hat{k}}\).
• Given \(\vec{A} = 2\hat{i} + 3\hat{j} + 4\hat{k}\): reading the scalars beside each unit vector gives \(A_x = 2,\; A_y = 3,\; A_z = 4\).

4 Analytical Addition & Subtraction

In unit-vector notation, vector addition and subtraction reduce to grouping and combining corresponding \(x\)-, \(y\)-, and \(z\)-components independently:

Worked Example A: Addition

\(\vec{A} = 2\hat{i} + 3\hat{j} + 4\hat{k}, \qquad \vec{B} = 5\hat{i} + 2\hat{j} + 1\hat{k}\)

\(\vec{R} = \vec{A} + \vec{B} = (2 + 5)\hat{i} + (3 + 2)\hat{j} + (4 + 1)\hat{k}\)
\(\vec{R} = \mathbf{7\hat{i} + 5\hat{j} + 5\hat{k}}\)
Worked Example B: Subtraction (Watch Negative Signs)

\(\vec{A} = 6\hat{i} + 5\hat{j} + 3\hat{k}, \qquad \vec{B} = 2\hat{i} + 1\hat{j} + 4\hat{k}\)

\(\vec{A} - \vec{B} = (6 - 2)\hat{i} + (5 - 1)\hat{j} + (3 - 4)\hat{k}\)
\(\vec{A} - \vec{B} = \mathbf{4\hat{i} + 4\hat{j} - \hat{k}}\)

5 Magnitude & Finding a Unit Vector in a Given Direction

Vector Normalization Formula:

To find the unit vector \(\hat{A}\) pointing in the exact direction of any non-zero vector \(\vec{A}\), divide the vector by its scalar magnitude:

$$\boxed{\hat{A} = \frac{\vec{A}}{|\vec{A}|}}$$
Worked Example 1 (2D Normalization):

Find the unit vector in the direction of \(\vec{A} = 3\hat{i} + 4\hat{j}\):

Step 1 (Magnitude): \(|\vec{A}| = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \mathbf{5}\)
Step 2 (Divide): \(\hat{A} = \frac{3\hat{i} + 4\hat{j}}{5} = \mathbf{0.6\hat{i} + 0.8\hat{j}}\)
Verification: \(|\hat{A}| = \sqrt{0.6^2 + 0.8^2} = \sqrt{0.36 + 0.64} = \sqrt{1} = 1\)
Worked Example 2 (3D Normalization):

Find the unit vector in the direction of \(\vec{B} = 2\hat{i} + 3\hat{j} + 6\hat{k}\):

Step 1 (3D Magnitude): \(|\vec{B}| = \sqrt{2^2 + 3^2 + 6^2} = \sqrt{4 + 9 + 36} = \sqrt{49} = \mathbf{7}\)
Step 2 (Unit Vector): \(\hat{B} = \frac{2\hat{i} + 3\hat{j} + 6\hat{k}}{7} = \mathbf{\frac{2}{7}\hat{i} + \frac{3}{7}\hat{j} + \frac{6}{7}\hat{k}}\)
