Extraction of Roots of Complex Numbers

De Moivre's Root Formula, Angular Symmetry, and Planar Polygon Distributions

1 Foundations of Complex Roots

In real arithmetic, equations such as \(x^2 = -4\) have no solutions because squares of real numbers are non-negative. In the complex number system \(\mathbb{C}\), the equation \(z^2 = -4\) has exactly two distinct solutions:

$$(2i)^2 = 4i^2 = -4 \quad \text{and} \quad (-2i)^2 = 4i^2 = -4 \implies z = \pm 2i$$
The Fundamental Multiplicity Principle:

Every non-zero complex number \(z \in \mathbb{C} \setminus \{0\}\) has exactly \(n\) distinct \(n\)-th roots in \(\mathbb{C}\):

  • Square roots \((n = 2) \implies 2\) distinct roots separated by \(180^\circ\) (\(\pi\) rad).
  • Cube roots \((n = 3) \implies 3\) distinct roots separated by \(120^\circ\) (\(\frac{2\pi}{3}\) rad).
  • Fourth roots \((n = 4) \implies 4\) distinct roots separated by \(90^\circ\) (\(\frac{\pi}{2}\) rad).

2 The General \(n\)-th Root Formula (De Moivre's Corollary)

Let a complex number be expressed in standard polar form: \(z = r(\cos\theta + i\sin\theta)\). Its distinct \(n\)-th roots \(C_k\) are calculated using:

General Root Identity:
$$\boxed{C_k = r^{1/n}\left[\cos\left(\frac{\theta + 2k\pi}{n}\right) + i\sin\left(\frac{\theta + 2k\pi}{n}\right)\right]}$$

where \(k = 0, 1, 2, \dots, n-1\)

Component Mathematical Meaning Structural Role
\(r^{1/n} = \sqrt[n]{r}\) Positive real \(n\)-th root of the modulus Constant radius of root circle
\(\theta\) Principal argument of the original number Starting angle parameter
\(2k\pi\) Successive full \(360^\circ\) revolutions Accounts for angular periodicity
Divide by \(n\) \(\theta_k = \frac{\theta + 2k\pi}{n}\) Yields the specific argument of root \(k\)
\(k \in \{0, \dots, n-1\}\) Generates exactly \(n\) unique outputs \(k \ge n\) produces redundant periodic duplicates

3 Standard Step-by-Step Curriculum Examples

Example 1: Square Roots of \(z = 1 + \sqrt{3}i\)
• Polar Form: \(r = \sqrt{1^2 + (\sqrt{3})^2} = 2\), \(\theta = \arctan(\sqrt{3}) = \frac{\pi}{3} \implies z = 2\left(\cos\frac{\pi}{3} + i\sin\frac{\pi}{3}\right)\).
• Root Parameters: \(n = 2 \implies r^{1/2} = \sqrt{2}\). Arguments: \(\theta_k = \frac{\pi/3 + 2k\pi}{2}\).
For \(k = 0\): \(\theta_0 = \frac{\pi/3}{2} = \frac{\pi}{6} \implies C_0 = \sqrt{2}\left(\cos\frac{\pi}{6} + i\sin\frac{\pi}{6}\right) = \mathbf{\frac{\sqrt{6}}{2} + \frac{\sqrt{2}}{2}i}\)
For \(k = 1\): \(\theta_1 = \frac{\pi/3 + 2\pi}{2} = \frac{7\pi}{6} \implies C_1 = \sqrt{2}\left(\cos\frac{7\pi}{6} + i\sin\frac{7\pi}{6}\right) = \mathbf{-\frac{\sqrt{6}}{2} - \frac{\sqrt{2}}{2}i}\)
Figure 1: Trigonometric Representation of Roots
Example 2: Cube Roots of \(z = 8i\)
• Polar Form: \(r = 8, \theta = \frac{\pi}{2} \implies z = 8\left(\cos\frac{\pi}{2} + i\sin\frac{\pi}{2}\right)\).
• Root Parameters: \(n = 3 \implies \sqrt[3]{8} = 2\). Arguments: \(\theta_k = \frac{\pi/2 + 2k\pi}{3}\).
\(k = 0 \implies \theta_0 = \frac{\pi}{6} \implies C_0 = 2\left(\cos\frac{\pi}{6} + i\sin\frac{\pi}{6}\right) = \mathbf{\sqrt{3} + i}\)
\(k = 1 \implies \theta_1 = \frac{5\pi}{6} \implies C_1 = 2\left(\cos\frac{5\pi}{6} + i\sin\frac{5\pi}{6}\right) = \mathbf{-\sqrt{3} + i}\)
\(k = 2 \implies \theta_2 = \frac{9\pi}{6} = \frac{3\pi}{2} \implies C_2 = 2\left(\cos\frac{3\pi}{2} + i\sin\frac{3\pi}{2}\right) = \mathbf{-2i}\)

4 Geometric Symmetry: The Circle Distribution

When plotted on the Argand plane, the \(n\) roots of any complex number lie precisely on a circle centered at the origin with radius \(R = \sqrt[n]{r}\), forming the vertices of a regular \(n\)-sided polygon.

Uniform Angular Separation:
$$\boxed{\Delta\theta = \frac{2\pi}{n} = \frac{360^\circ}{n}}$$
Root Order Root Count (\(n\)) Angular Separation (\(\Delta\theta\)) Geometric Polygon
Square Roots \(2\) \(\pi = 180^\circ\) Collinear opposite diameter
Cube Roots \(3\) \(\frac{2\pi}{3} = 120^\circ\) Equilateral triangle
Fourth Roots \(4\) \(\frac{\pi}{2} = 90^\circ\) Square
Fifth Roots \(5\) \(\frac{2\pi}{5} = 72^\circ\) Regular pentagon

5 Challenging Examination Worked Examples

Advanced Example 1: Fourth Roots of \(z = -16\) Polynomial \(z^4 + 16 = 0\)

Find all four solutions to \(z^4 = -16\) and express each root in exact rectangular form \(a + bi\).

• Polar Form: \(r = 16\), \(\theta = \pi \implies z = 16(\cos\pi + i\sin\pi)\).
• Root Modulus: \(R = \sqrt[4]{16} = \mathbf{2}\).
• Angle Rule: \(\theta_k = \frac{\pi + 2k\pi}{4}\) for \(k = 0, 1, 2, 3\).
\(k = 0 \implies \theta_0 = \frac{\pi}{4} \implies 2\left(\frac{\sqrt{2}}{2} + i\frac{\sqrt{2}}{2}\right) = \mathbf{\sqrt{2} + \sqrt{2}i}\)
\(k = 1 \implies \theta_1 = \frac{3\pi}{4} \implies 2\left(-\frac{\sqrt{2}}{2} + i\frac{\sqrt{2}}{2}\right) = \mathbf{-\sqrt{2} + \sqrt{2}i}\)
\(k = 2 \implies \theta_2 = \frac{5\pi}{4} \implies 2\left(-\frac{\sqrt{2}}{2} - i\frac{\sqrt{2}}{2}\right) = \mathbf{-\sqrt{2} - \sqrt{2}i}\)
\(k = 3 \implies \theta_3 = \frac{7\pi}{4} \implies 2\left(\frac{\sqrt{2}}{2} - i\frac{\sqrt{2}}{2}\right) = \mathbf{\sqrt{2} - \sqrt{2}i}\)

Combined Solution: \(z = \pm\sqrt{2} \pm \sqrt{2}i\).

Advanced Example 2: Cube Roots of Mixed Number \(z = -2 + 2i\) Quadrant II Cube Roots

Determine all cube roots of \(z = -2 + 2i\) in trigonometric polar form.

• Modulus: \(r = \sqrt{(-2)^2 + 2^2} = \sqrt{8} = 2^{3/2}\).
• Argument: In QII (\(x<0, y>0\)): \(\theta = \pi - \frac{\pi}{4} = \frac{3\pi}{4}\).
• Root Modulus: \(R = \left(2^{3/2}\right)^{1/3} = 2^{1/2} = \mathbf{\sqrt{2}}\).
• Angle Rule: \(\theta_k = \frac{3\pi/4 + 2k\pi}{3} = \frac{\pi}{4} + \frac{2k\pi}{3}\).
\(k = 0 \implies \theta_0 = \frac{\pi}{4} \implies \mathbf{C_0 = \sqrt{2}\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right)}\)
\(k = 1 \implies \theta_1 = \frac{\pi}{4} + \frac{2\pi}{3} = \frac{11\pi}{12} \implies \mathbf{C_1 = \sqrt{2}\left(\cos\frac{11\pi}{12} + i\sin\frac{11\pi}{12}\right)}\)
\(k = 2 \implies \theta_2 = \frac{\pi}{4} + \frac{4\pi}{3} = \frac{19\pi}{12} \implies \mathbf{C_2 = \sqrt{2}\left(\cos\frac{19\pi}{12} + i\sin\frac{19\pi}{12}\right)}\)

6 The 5-Step Execution Protocol & Exam Traps

Systematic Protocol:
  1. Convert the given Cartesian number into standard polar form \(r(\cos\theta + i\sin\theta)\).
  2. Identify the required root order \(n\), and record the counter index \(k \in \{0, 1, \dots, n-1\}\).
  3. Calculate the uniform root radius \(R = r^{1/n}\).
  4. Evaluate angles using \(\theta_k = \frac{\theta + 2k\pi}{n}\) for each value of \(k\).
  5. Substitute into \(C_k = R(\cos\theta_k + i\sin\theta_k)\) and convert to rectangular form if asked.
Top 3 Student Errors to Avoid:
  • Starting \(k\) at 1: \(k\) must always begin at \(0\) and terminate at \(n - 1\).
  • Dividing only \(2k\pi\) by \(n\): The entire sum \((\theta + 2k\pi)\) must be divided by \(n\).
  • Dividing the modulus instead of root: The modulus is \(r^{1/n} = \sqrt[n]{r}\), NEVER \(\frac{r}{n}\)!
